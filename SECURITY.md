# Security

- **Secrets**: Never commit `.env`, cookies, or session tokens. The repository ignores `.env` by default; keep it that way.
- **Local deployment**: Bind to `127.0.0.1` unless you understand the risks of exposing the app on a network.
- **Reporting**: If you find a security issue in this project’s code, please open a private discussion or issue with details so it can be addressed responsibly.
